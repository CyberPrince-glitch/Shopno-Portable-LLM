Features

Everything a local AI stack needs

From quantized local models to agent skills — one app replaces a dozen tools.

Local LLM Inference

llama.cpp with TurboQuant KV-cache and MLX on Apple Silicon. Run GGUF & MLX models at full speed on your own hardware — no API bills, ever.

OpenAI-Compatible API

A local server at localhost:1337/v1 speaks the OpenAI protocol. Point Claude Code, Codex CLI, OpenCode, Hermes or any SDK at it — done.

MCP Servers Built In

Cyber Prince, Shopno, wigolo and fetch MCP servers ship ready to run — extend the assistant with tools, search and automation out of the box.

1,800+ Prebuilt Skills

Every prebuilt skill ships with the app. The AI automatically activates the right skill for your question — no manual setup, no wasted context.

Agentic & Persistent

Multi-step tool use with approval gates, model-switch handoff so work is never lost, and crash-resilient history — assign a task and let it run.

Shopno Cloud Ready

Prefer managed models? Log in and get cloud models alongside your local ones — favorite them, switch freely, keep your history intact.

Developer first

Works with the tools you already use

Any OpenAI SDK, any coding agent — just change the base URL.

terminal — bash
# 1. Point any OpenAI client at your local Shopno server
$ curl http://localhost:1337/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{ "model": "local-model", "messages": [{"role":"user","content":"hello!"}] }'

{ "choices": [{ "message": { "content": "Hi! Running fully offline 🎉" } }] }

# 2. Or launch a coding agent against it
$ ANTHROPIC_BASE_URL=http://localhost:1337/v1 claude
