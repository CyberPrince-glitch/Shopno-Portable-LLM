হ্যাঁ, Shopno AI একটি ওপেন-সোর্স এবং সম্পূর্ণ বিনামূল্যে ব্যবহারের উপযোগী সার্বভৌম এআই প্ল্যাটফর্ম। আপনি কোনো প্রকার ক্রেডিট কার্ড বা মাসিক সাবস্ক্রিপশন ফি ছাড়াই উইন্ডোজ এবং অ্যান্ড্রয়েডের জন্য ডাউনলোড করে আজীবন ব্যবহার করতে পারবেন।
এই ল্যান্ডিং পেজে একটি লাইভ GitHub Releases API অটো-সিঙ্ক ইঞ্জিন রয়েছে। যখনই ডেভেলপার GitHub এ নতুন কোনো রিলিজ (.exe, .apk, .msi) ট্যাগ সহ পাবলিশ করেন, ব্রাউজার স্বয়ংক্রিয়ভাবে লেটেস্ট ভার্সন, ফাইলের সাইজ এবং ডিরেক্ট ডাউনলোড লিঙ্ক আপডেট করে দেয়। আপনাকে ম্যানুয়ালি লিংক বদলাতে হয় না!
না, কোনো ডেডিকেটেড জিপিইউ থাকা বাধ্যতামূলক নয়! Shopno AI এর অপটিমাইজড কোয়ান্টাইজড ইঞ্জিন (CPU TurboQuant) সাধারণ ইন্টেল বা এএমডি প্রসেসরেও অতি দ্রুত চলে। আর ক্লাউড মোডে চালালে আপনার সাধারণ ল্যাপটপেই সুপারকম্পিউটারের স্পিড পাবেন।
Shopno AI চালু করার সাথে সাথে ব্যাকগ্রাউন্ডে একটি লাইটওয়েট সার্ভার চালু হয় যা হুবহু OpenAI API স্ট্যান্ডার্ড মেনে চলে। আপনি Claude Code, Cursor, Aider কিংবা আপনার নিজস্ব পাইথন/জাভাস্ক্রিপ্ট কোডে Base URL হিসেবে http://localhost:1337/v1 এবং যেকোনো ডামি API Key দিলেই কাজ করবে!
